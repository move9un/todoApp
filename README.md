# ✅ 투두리스트 - React 기반 To-Do App

나만의 할 일을 관리하는 투두앱입니다.  
다크모드, 태그 필터, 진행률 바 등 기본기를 탄탄하게 다진 감각적인 프로젝트입니다.

---

## ✨ 주요 기능

- ✅ 할 일 추가 / 삭제 / 완료 체크
- 🌓 다크모드 지원 (로컬 저장)
- 🏷️ 태그 지정 및 태그별 필터링
- 🔁 새로고침에도 유지되는 localStorage 저장
- 📊 완료율 퍼센트 + 진행률 바
- 🎨 반응형 디자인 & 세련된 버튼 UI

---

## 🛠️ 사용 기술

| 구분     | 기술 |
|----------|------|
| 프론트엔드 | React, CSS Modules |
| 상태관리 | useState, useEffect |
| 저장 방식 | LocalStorage (MongoDB 연동 예정) |
